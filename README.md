## ✨ Các Tính Năng Nổi Bật Của Website

1. **Bộ Lọc Dự Án Thông Minh (Filterable Gallery)**: Lọc tức thì theo danh mục: *Tất cả*, *Dự án WI.CAN*, *Dự án WIPA*, *Brand Guidelines*, *Bản vẽ phác thảo*.
2. **Trình Xem Ảnh Toàn Màn Hình (Fullscreen HD Lightbox)**: Phóng to xem chi tiết các thông số kỹ thuật của bản vẽ và poster với độ phân giải gốc. Hỗ trợ phím tắt `Esc`, mũi tên điều hướng.
3. **Case Study Chi Tiết Chuyên Sâu**: Khám phá chiều sâu triết lý thiết kế, sứ mệnh, giá trị cốt lõi và các hạng mục bàn giao.
4. **Bảng Màu Tương Tác (Click-to-Copy HEX Color)**: Nhấp trực tiếp vào các ô màu (#5A2CA0, #7ED1C4, #D4AF7C, #A30D1B, #2E7D32) để tự động sao chép mã HEX kèm thông báo Toast.
5. **Nút Chuyển Chế Độ Giao Diện 3 Trạng Thái (Dark / Light / Theo thiết bị)**:
   - ☀️ **Sáng (Light Mode)**: Phong cách tinh tế, tôn vinh hình ảnh và bản vẽ nền sáng.
   - 🌙 **Tối (Dark Mode)**: Phong cách huyền bí, luxury glassmorphism với ánh sáng vi mô.
   - 💻 **Theo thiết bị (System Auto)**: Tự động phát hiện và đồng bộ theo cài đặt Dark/Light của máy tính/điện thoại (lắng nghe `prefers-color-scheme`), lưu cài đặt vào `localStorage` chống giật màn hình (anti-flicker).
6. **Form Đặt Lịch Tư Vấn Dự Án**: Giao diện tương tác chuyên nghiệp cho khách hàng gửi brief và yêu cầu báo giá.
7. **Tương Thích Mọi Thiết Bị**: Hiển thị mượt mà trên Desktop, Laptop, Máy tính bảng và Điện thoại thông minh.

## 🚀 Cách Mở & Xem Website

### Cách 1: Mở Trực Tiếp Bằng Trình Duyệt
Nhấp đúp chuột trực tiếp vào file [index.html](file:///Users/trgiahuy/Desktop/website-demo/index.html) để mở trên Google Chrome, Safari hoặc trình duyệt bất kỳ.

### Cách 2: Khởi Chạy Bằng Local Server
Tại thư mục `website-demo`, chạy một trong các lệnh sau trong terminal:

```bash
# Sử dụng Python 3
python3 -m http.server 3000

# Hoặc sử dụng Node.js (npx)
npx serve
```
Sau đó mở trình duyệt và truy cập: `http://localhost:3000`
